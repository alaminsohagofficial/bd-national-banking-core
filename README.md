# BD National Banking & Unified Switching Core Engine

## 📌 Project Overview
This repository hosts the unified master banking interface, transaction simulation engine, PDF statement generator, and inter-bank clearing pipelines (NPSB / BEFTN / RTGS).

## 🚀 Key Modules
- **Unified Dashboard:** Real-time account balance monitoring for Sonali e-Wallet.
- **Inter-Bank Switching Simulator:** Real-time balance deduction logic via NPSB, BEFTN, and RTGS channels.
- **SMS Payload Engine:** Dual-party transaction notifications for remitter and beneficiary.
- **Audit & Verification:** Official A4 Balance Confirmation Certificate and Bank Statement PDF templates.

## 🔒 Security Notice
This repository is restricted to authorized administrative personnel for national financial architecture management.
